# 像锚架构总览

像锚把本地素材工作台、生成任务和结果文件放在同一台电脑上运行。当前产品重点是让一次授权人像编辑有明确的输入、执行状态和可复盘的输出。

```text
React 工作台
  素材与红圈 → 原图理解 → 提示词 → 批量任务 → 结果归档
       │                         │
       └──────── Electron preload IPC ────────┘
                         │
Electron 主进程
  文件/项目保存 ── ChatGPT 网页自动化 ── 用户自配 API
                         │
                结果校验、断点与归档
```

## 主要模块

- `src/App.tsx`：界面工作流与任务状态，连接素材、提示词、生成和结果归档。
- `src/renderer/prompt/`：把当前主图、参考图、原图理解和编辑约束组合为提示词；素材变化时旧草稿失效。
- `src/renderer/state/`：项目与设置状态。项目记录操作输入和归档结果，密钥不写入普通项目。
- `src/preload/index.ts`：向渲染层暴露限定的 IPC 接口。
- `src/main/index.ts`：主进程入口，负责文件、浏览器会话、API 调度、断点与结果落盘。
- `src/main/chromeChatGpt.ts`、`src/main/geminiWebAutomation.ts`：网页路线的浏览器控制与页面适配。Gemini 网页入口目前不可选。
- `src/main/lianyilianRelayTransport.ts`、`src/main/relayBatchJournal.ts`：API 传输与事务状态。付费请求状态不明时不能当作安全重试。
- `src/main/imagePersistence.ts`、`src/main/cameraRealism.ts`：结果校验、保存和独立副本处理。

## 数据与兼容

开发模式默认使用源码目录下的 `.local-data/`，正式版本使用应用数据目录。改名后会优先读取已存在的旧版数据目录和浏览器会话分区，避免把升级用户当成新用户。项目、结果、浏览器资料和加密凭据都不应包含在对外分享的源码包中。

当前闭环由人审核结果并决定下一次修正；案例检索、自动策略更新和线上业务效果评测仍属于下一阶段。
