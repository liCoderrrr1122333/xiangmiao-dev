# 耀创工坊 0.1.5 发布加固记录

## 发布目标

- 保持 0.1.4 的原图分析、自动做图、批量恢复、一键蒙脸和参考图流程。
- 解决 Electron 内置窗口中的 Google 登录白屏。
- 登录成功后让专属 Chrome 在后台运行且不显示任务栏窗口。
- 提升商业界面的信息层次、动效质量和 1280x720 可用性。

## 问题记录

### 1. Google 登录页全白

- 现象：ChatGPT 内置窗口点击“使用 Google 账户继续”后，页面 URL 已进入 `accounts.google.com`，但标题、正文和 DOM 均为空。
- 根因：Google OAuth 在 Electron 嵌入式浏览器中无法稳定完成页面渲染。
- 解决：拦截 Google OAuth，持久切换到耀创工坊专属真实 Chrome；在该资料目录中重新进入 ChatGPT 并触发 Google 登录。
- 经验：不能只根据 URL 或加载事件判断登录页可用，显示前必须探测标题、正文、DOM、登录面板或输入框。

### 2. Headless Chrome 停在“请稍候”

- 现象：`--headless=new` 可连接 CDP，且 `navigator.webdriver=false`，但 ChatGPT 长时间停留在 Cloudflare“请稍候”页。
- 根因：ChatGPT 的浏览器校验对 headless 运行方式更敏感；复用可见模式资料也不能稳定通过。
- 解决：后台自动化改用完整 headed Chrome 渲染，并通过 Windows `ShowWindow` 原生隐藏窗口；后台窗口不出现在任务栏。
- 经验：浏览器自动化的可连接不等于业务页面可用，必须同时验证实际正文、资源数量和输入框。

### 3. 上次浏览器模式残留

- 现象：可见登录 Chrome 异常退出后，下一次后台实例可能占用同一资料目录或调试端口。
- 根因：模式文件与浏览器进程生命周期可能不同步。
- 解决：记录固定非零 CDP 端口和运行模式；切换模式前关闭仍存活的受管浏览器，并等待端口释放。
- 经验：持久资料目录、浏览器进程、调试端口和当前控制目标必须作为一个生命周期管理。

### 4. 浅色主题对比度下降

- 现象：星轨深色样式加入后，浅色主题中的部分标题和说明仍使用深色模式白字。
- 根因：旧样式中的固定颜色优先级高于主题变量。
- 解决：补充浅色主题语义覆盖，保留深色图片画布，其余面板、表单和文字恢复深色高对比。
- 经验：视觉改造必须覆盖所有已存在主题，不能只验收默认主题。

## 自动化保护

- 原图分析保留 DOM、对话正文和文稿候选的多来源读取。
- 已发送但未写回的分析对话会记录并续读，不重复上传或发送。
- 分析成功后清理对话，避免影响后续图片生成。
- 每张图片最多尝试三次，批量任务总时限两小时。
- 批量断点只继续缺失图片，不重复发送已保存任务。
- ChatGPT 明确返回生成失败时立即结束本轮等待。
- 保存结果统一校验并归一化为原始主图像素尺寸。
