# 耀创工坊 0.4.0 安全审计报告

## 执行摘要

本次审计覆盖 Electron 主窗口、preload/IPC、内置 ChatGPT 会话、外链与目录打开、后期图片输入、临时文件、清单恢复、桌面导出和依赖供应链。已关闭审计中发现的 IPC 调用者校验和远程页面权限过宽问题；当前没有未解决的 Critical、High 或 Medium 项。

## Critical

无。

## High

无。

## Medium

### SEC-001 已关闭：IPC 未逐次验证调用者

- 影响：若主窗口未来意外导航到非本地页面，外部页面可能尝试调用 preload 暴露的文件和自动化能力。
- 证据：`src/main/index.ts:6796-6834`。
- 修复：只接受当前主窗口、顶层 frame 和受信本地 URL 发起的 IPC；主窗口 `will-navigate` 同时阻止外部页面替换工作台。
- 验证：安全策略测试和 Electron 运行时外部文件导航测试通过，正常设置、自动保存和后期 IPC 仍可用。

### SEC-002 已关闭：内置 ChatGPT 自动放行全部来源权限

- 影响：受信远程来源若请求相机、麦克风、定位或通知，旧规则会无条件放行权限类型。
- 证据：`src/main/index.ts:1218-1226`。
- 修复：受信 ChatGPT/OpenAI 来源也只允许 `clipboard-sanitized-write`；其他权限全部拒绝。远程窗口继续保持 `nodeIntegration: false`、`contextIsolation: true` 和 `sandbox: true`。
- 验证：类型检查、安全策略测试和 Electron 壳层测试通过；专属真实 Chrome 登录路径不使用该 Electron 分区。

## Low

### SEC-003 已关闭：外链和目录打开需要参数约束

- 证据：`src/main/index.ts:763-782`。
- 措施：外链只允许 HTTPS 或本机开发地址；目录必须是长度受限的绝对路径且实际存在，普通技术错误不会直接进入系统 shell。

### SEC-004 已关闭：后期文件路径和 IPC 图片体积需要边界

- 证据：`src/main/postProcessingStore.ts:45-129`、`src/main/postProcessingStore.ts:402-423`。
- 措施：临时文件必须位于明确根目录；图片 ID、尺寸、清单大小、单张编码大小、合计编码字符数和单批数量均有限制；删除只读取当前清单列出的相对路径。

### SEC-005 已关闭：图片和清单写入需要抗中断

- 证据：`src/main/postProcessingStore.ts:187-235`、`src/main/postProcessingStore.ts:367-395`。
- 措施：JPG 和清单均先写临时文件并验证，再原子替换；主清单损坏时恢复备份，双清单损坏时隔离文件且不删除孤立 JPG。

### SEC-006 已关闭：渲染器隔离与 CSP

- 证据：`src/main/index.ts:6841-6852`、`index.html:5-8`。
- 措施：主渲染器启用沙箱、上下文隔离并禁用 Node 集成；CSP 默认仅允许本地资源，禁用对象、frame、base 和表单提交。

### SEC-007 已关闭：依赖已知漏洞

- 措施：使用 npm 官方审计端点分别检查生产依赖和全部依赖。
- 结果：均为 0 个已知漏洞。

## 残余风险

- 正式主界面仍通过打包后的 `file://` 页面加载。Electron 最新清单更推荐自定义协议，但现有页面受 CSP、导航阻断、顶层 frame 和 IPC 调用者联合校验保护；0.4.0 不做高风险协议迁移。
- ChatGPT 和 Google 页面属于远程服务，服务端 DOM 与登录策略可能变化。远程页面不获得耀创工坊 preload，Google OAuth 也不会被自动点击。
- 完整像素后期处理属于本地高内存操作；边界超出设备能力时会返回失败并保留临时源图，而不是删除或生成不完整文件。
