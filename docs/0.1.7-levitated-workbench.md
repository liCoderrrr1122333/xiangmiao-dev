# 耀创工坊 0.1.7 平视 2.5D 视觉升级记录

## 目标

- 在不改变三栏工作流、功能入口、数据结构和自动化流程的前提下，将界面升级为平视 2.5D 轻立体悬浮风格。
- 保持 `1280×720` 最低正式支持分辨率下的三栏布局。
- 深色、浅色和动效降级模式都保持可读、可操作。

## 变更

- 新增独立的 `levitated-workbench.css` 视觉层，基础样式与新版主题可以单独回滚。
- 顶栏、面板、输入区、工具按钮和主要操作按钮采用统一的凸起、接触阴影和内凹层级。
- 用红、蓝、青绿、紫和琥珀色区分主图、参考、分析、工作流和状态，不改变原有功能位置。
- 入场动效只用于顶栏和三列容器，AI 分析中的扫描动效限定在状态条内。
- 完整支持浅色主题、减少动效、关闭动效和系统减少动效偏好。

## 问题记录

### 1. 最低分辨率下 AI 分析按钮文字被截断

- 现象：在 `1280×720` 三栏界面中，中栏标题说明占用最小宽度，按钮右侧文字显示不完整。
- 根因：标题副文案未设置可收缩边界，按钮也没有固定为不可压缩项。
- 解决：为标题容器补充 `min-width: 0`，在窄三栏下对副文案使用省略显示，并保持按钮完整宽度。
- 经验：响应式验收不能只检查页面横向滚动，还要检测按钮自身的 `scrollWidth` 与 `clientWidth`。

### 2. 浅色主题的生成数量步进器发生挤压

- 现象：数字输入框覆盖单位文字，按钮和输入区宽度不稳定。
- 根因：新版通用输入框和按钮样式覆盖了步进器原有的固定网格尺寸。
- 解决：恢复步进器按钮的 30 像素稳定宽度，并为浅色主题的输入、标签和边框增加组件级样式。
- 经验：通用控件材质必须为固定格式控件保留明确例外。

### 3. 浅色主题设置弹窗对比度不足

- 现象：弹窗背景仍为深色，但标题切换为深色文字。
- 根因：新版最高层级弹窗只定义了深色材质，没有定义浅色主题对应面。
- 解决：补充浅色弹窗、分组面板、标题、阴影和边框样式。
- 经验：主题验收必须覆盖主界面之外的弹窗和悬浮结果层。
