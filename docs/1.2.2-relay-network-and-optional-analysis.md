# 耀创工坊 1.2.2 API 网络与可选原图理解

更新时间：2026-08-25

## 问题现象

- API 在检查连接时可能直接返回 `ECONNRESET` 或 `fetch failed`，导致未进入图片生成。
- 分享安装包后，有些用户不使用代理，有些用户使用 Windows 系统代理；固定走单一路径会让另一类环境更容易失败。
- API 做图时原图理解始终展开且参与提示词，用户不能明确选择“直接依据主垫图生成”。
- 关闭原图理解后，旧检查清单仍会提示缺少场景、姿态、面部和光影描述，状态表达不一致。

## 真实根因

- API 传输层没有把直连和 Electron 系统代理作为有顺序的候选网络路径，也没有复用已经验证成功的路径。
- 每次批次前重复执行相同的模型权限探测，增加了不必要的连接次数。
- 提示词构建和检查清单此前默认总是读取四段原图分析及网感姿势，没有 API 专用的显式关闭状态。

## 解决方式

- API 默认先使用 Node 直连；只有直连发生超时、连接重置、DNS、TLS 等连接级错误时，才回退到 Electron/Windows 系统代理。
- 401/403、429、模型未开放等业务错误不会切换网络路线，也不会被掩盖成代理问题。
- 成功探测后按当前 Key、Base URL 和模型的 SHA-256 签名缓存本次运行结果，并继续使用已经验证的网络路径；签名不保存原始 Key。
- 付费图片生成 POST 不自动重试；URL 图片下载中断只允许安全重试一次，避免重复扣费。
- API 模式新增“使用原图理解”开关，默认关闭并折叠。关闭时一键提示词不读取场景、姿态、面部朝向、光影妆容和旧网感姿势，直接依据主垫图；人脸参考、穿搭参考、红圈保护和原尺寸规则继续生效。
- 开启后恢复原有 AI 分析、网感姿势和四段原图理解流程。开关变化会使旧提示词失效，必须重新生成。
- 检查清单与开关同步，关闭时不再显示四项无关分析建议。
- 安装包仅携带固定公开接口配置，不携带用户 API Key。Key 仅本次运行有效；用户主动勾选“记住本机”时才进入 Electron `safeStorage`。

- API 原图理解关闭分支先以失败测试证明检查清单仍含四项分析建议；修复后提示词和清单均不再读取这些内容。

## 经验教训

- 分享型桌面软件应优先使用不依赖用户代理配置的直连路径，再把系统代理作为连接失败后的备用路径。
- 网络回退只能处理传输故障，不能把鉴权、余额、模型权限或服务商异常伪装成网络已恢复。
- 付费生成请求必须保持至多一次提交；允许重试的是无副作用的能力探测和结果下载。
- 可选分析必须同时约束 UI、提示词来源、旧草稿失效和检查清单，不能只隐藏界面。
