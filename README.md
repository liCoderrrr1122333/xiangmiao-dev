# 耀创工坊

耀创工坊是一款“红圈区域锁定 + Image 2.0 提示词 + 授权人像编辑工作流”桌面软件。

## 当前源码

当前版本为 `1.2.4`。首次修改请阅读 [开发与源码分享说明](docs/DEVELOPMENT.md)；维护记录见 [MAINTENANCE_HANDOFF.md](docs/MAINTENANCE_HANDOFF.md)。历史安装包不一定包含尚未发布的源码修复。

- 新用户默认进入自由 API 做图，可选本地模型分析；API 地址与 Key 由使用者自行配置，原图理解可选。
- ChatGPT 支持极简直传、按通道复用对话及保护暂停。人工登录或安全验证期间不自动刷新；人工完成后主动检查恢复，不以关闭网页提示作为解锁依据。
- Gemini 入口暂不可选，保留代码与夹具测试不代表真实服务已验收。
- `npm run dev` 先构建主进程和预加载，再启动页面。开发数据默认在源码目录 `.local-data/`，与已安装版隔离。

它是一款桌面端“授权人像区域编辑提示词工作台”，用于整理：

- 主垫图原图
- 红圈人脸区域
- 一张或多张人脸参考图
- 原图场景、动作、面部朝向、光影、妆容和画质描述
- 给 ChatGPT 或 Gemini 网页做图使用的区域锁定编辑提示词
- ChatGPT / Gemini 自动发送、并行生成、断点续做、结果归档和二次修正提示词

最高优先级规则：

> 只编辑提示词明确授权的人脸、发型、网感姿势与指定穿搭区域；其他内容保持原图不变。

## 技术栈选择

本项目使用 Electron + React + TypeScript + Vite。

原因：

- Windows 桌面端打包成熟，可输出 `.exe` 安装包。
- 可通过安全 IPC 调用系统剪贴板、文件导出、打开文件夹、打开 ChatGPT。
- 包含 macOS 构建配置；实际 `.app`、DMG、签名和公证需要在 Mac 上单独验收。
- React + TypeScript 适合快速构建复杂图像工作台 UI。

## 核心功能

- 专业深色图像工作台 UI，支持浅色主题切换。
- 主图上传：点击、拖拽、粘贴，支持 jpg / jpeg / png / webp。
- Canvas 红圈标注：绘制、移动、缩放、清除、导出红圈预览图。
- 红圈数据：中心点、宽度、高度、覆盖范围。
- 参考图管理：多图上传、拖拽排序、删除、设置主参考图、标签、备注。
- 描述面板：场景、动作姿态、面部朝向、光影妆容、禁止改变内容、强度滑块。
- PromptBuilder 独立模块：区域编辑定制版、自定义草稿和二次修正。
- 生成前检查清单和发送前检查面板。
- 一键复制提示词、金色自定义微调、发送快照和结果归档。
- ChatGPT 网页与自由 API 做图通道；极简直传不探测或切换网页模型。
- 1 / 2 / 3 路独立标签页并行做图，支持失败识别和按任务编号断点续做。
- “打开做图网页”自动上传、发送、等待、保存和批量断点续做流程。
- 自动导出发送包文件夹和 `09_send_package.zip`。
- 发送历史记录，可重新复制、打开文件夹、打开对应服务商网页。
- 结果图拖回归档、评分、备注、标记成功或需要修正。
- 二次修正提示词，多问题组合生成。
- 设置页面：基础设置、网页自动化设置、AI 分析设置和 API 直接生成设置。

## 安全和授权说明

本软件只用于授权图像编辑工作流管理。ChatGPT 网页自动化只在用户本机的独立浏览器资料中运行；登录资料不会导出、不会写入项目文件，也不会上传到开发者服务器。软件不会抓取或展示账号 Token。

本软件不会实现：

- 导出或上传用户浏览器 Cookie。
- 抓取用户 ChatGPT Token。
- 绕过 ChatGPT 平台限制。
- 模拟盗用登录态。
- 自动冒充他人发送内容。
- 伪造证件、诈骗材料、政治误导材料。
- 未经授权的人脸替换。
- 色情勒索或侵犯隐私相关功能。
- 规避水印或绕过安全规则的功能。

## 网页自动化模式

切换制作通道为 ChatGPT 后使用独立 Chrome 登录资料。账号、验证码、人机验证和 Google 安全步骤始终由用户手动完成；检测到人工验证时停止页面操作，直到用户主动检查恢复。Gemini 代码尚未完成当前真实页面适配，界面入口暂不可选。

ChatGPT 做图流程包括：

1. 检查项目完整性。
2. 检查授权确认。
3. 自动保存当前项目到自动保存文件。
4. 导出原始主图。
5. 导出带红圈主图。
6. 导出参考图。
7. 导出提示词 txt。
8. 导出提示词 markdown。
9. 导出操作说明文件。
10. 导出项目 manifest。
11. 导出项目 JSON。
12. 生成发送包 zip。
13. 冻结本批次的服务商、模型、附件、提示词、数量和并行数。
14. 自动上传本轮附件并核对附件证据。
15. 自动发送并确认网页真正接收本轮消息。
16. 只读取本轮新回复，明确失败时停止等待并给出可读原因。
17. 等待并校验本轮结果，保存结果与归档记录。
18. 批量中断时只继续缺失任务，不重复发送已成功任务。
19. 保存发送历史和结果归档。

手动模式建议按这个顺序上传：

1. 带红圈标记的主垫图，启用蒙脸时使用蒙脸后的版本。
2. 人脸及可选穿搭参考图，不额外上传未标记原图。
3. 粘贴完整提示词。
4. 发送请求进行编辑。

核心规则：红圈内可编辑，红圈外完全不变。

## API 直接生成模式

在制作通道选择 API，填写自己的服务地址和 Key。高级选项可配置协议、模型与接口路径，必须与服务商实际文档一致。

说明：

> API 调用使用你填写的服务与 Key，可能产生费用，不等于网页会员额度。图片与提示词会发送给你配置的服务商，请先确认其可信性与计费方式。

当前实现：

- API Key 默认仅保存在主进程本次运行内存，输入框提交后不回显明文。
- 勾选“记住本机”后由 Electron `safeStorage` 加密保存；不可用时拒绝明文保存。
- Key 不写入普通设置、项目、断点或发送包，安装包不包含个人 Key。
- 同一个正在执行的任务编号不能重复提交。取消后迟到的结果不能被当作成功返回。
- 生成提交状态不确定时不自动重新提交付费请求。图片下载与生成是不同阶段。

默认优先直连。应用不能绕过系统级 TUN、服务商故障或配额限制，也不能保证任意 API 协议自动兼容。

## 网页模式和 API 模式区别

- 网页模式：依赖 ChatGPT 网页布局和人工登录，不绕过访问保护。
- API 模式：使用用户配置的接口和密钥，不需要浏览器登录；分析可独立选择本地模型或 ChatGPT。

## 重要源码说明

## 常见问题

### 软件会自动登录 ChatGPT 或 Gemini 吗？

不会替用户输入账号、密码或验证码。用户需在专属 Chrome 中自行完成登录；登录成功后，软件会在本机独立资料目录中复用该登录状态执行自动化。

### 为什么要同时导出原图和红圈图？

原图是最终构图和场景基准，红圈图用于帮助 ChatGPT 理解唯一允许编辑的人脸区域。

### 如果生成结果修改了红圈外内容怎么办？

回到软件的“二次修正提示词”面板，勾选“红圈外内容被改动”等问题，复制修正提示词继续追问。

### API Key 会保存吗？

默认仅本次运行使用。勾选“记住本机”后加密保存；可在配置窗口清除。分享源码必须排除 `.local-data` 和任何用户数据目录，不能只依赖加密保护。

## 商业发布与源码保护

Electron 安装包无法做到源码绝对不可恢复。当前配置为非 ASAR 打包，应用文件清单限定为构建产物、生产依赖和图标资源。分享源码时接收者可以阅读和修改代码，不能依赖混淆保护密钥；分发前仍需检查产物内容及第三方许可。

## 已知限制

- Google、ChatGPT、Gemini 或 Cloudflare 的页面结构和安全策略可能变化；软件会阻止空白窗口、给出可恢复错误并保留重试入口，但第三方服务可用性不由本软件控制。
- 专属 Chrome 需要本机安装 Google Chrome；未安装时会尝试 Microsoft Edge。
- 自由 API 仅适配当前实现的协议；模型列表可读不等于生成接口、余额和并发额度一定可用。
- 红圈画布支持绘制、移动和角落缩放，后续可增强为更精细的控制柄和多级撤销。
- 示例项目只填充文字，不内置真实人物图片。
