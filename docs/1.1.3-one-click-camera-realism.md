# 1.1.3 一键相机质感副本

日期：2026-08-22  
正式版本：`1.1.3`

## 现象

Hale 希望把 `camera-realism-code-only.zip` 中的相机成像后处理能力接入耀创工坊，作为结果图的一键降低 AI 感功能，并把入口放在“结果归档”标题栏、“查看全部”左侧，以金色边框明确提示。

源 ZIP 的 SHA-256 为：

`1C0E3C42A4C3FC71371CA3E963FB51DA2F5358C2D45EF43080C119EB9B325F10`

## 根因与边界

- Windows 客户端不能假设用户已安装 Python、Pillow 或 NumPy。
- 固定随机种子会让批量图片重复出现同一纹理指纹。
- 该处理允许改变全图像素和局部细节，因此不能继续服从正式做图阶段的红圈外像素锁定。
- 本地后处理不能保证通过某个特定 AI 检测器，界面不承诺具体检测率结果。
- 原结果属于项目证据，不能被覆盖或静默替换。

## 解决方式

- 使用项目已有 Node/Electron 链路中的 `sharp 0.35.3` 实现，不打包 Python 运行时，也不接入外部服务。
- 加入轻微镜头畸变、色差、色调增益、对比度、暗角、明暗相关颗粒、锐化和 JPEG 4:2:0 输出。
- 噪点种子由输入图片 SHA-256 派生：同一输入可复现，不同图片不会共用固定纹理。
- 在“结果归档”标题栏增加唯一的金色“一键降 AI 感”按钮，位置紧邻“查看全部”左侧；结果卡片中不再重复放置入口。
- 每次处理生成独立 `*_相机质感.jpg`，重名时追加 `_2`、`_3`，永不覆盖原结果；成功后作为新结果加入归档并保留提示词快照。
- 全尺寸本地读取仅限当前桌面项目目录，并校验目录包含、真实路径和符号链接边界；手动导入结果使用自身图片数据。
- 保存采用临时文件、JPEG 格式与尺寸复核、原子重命名。

## 经验教训

- “降低 AI 感”适合作为结果归档后的可撤销派生操作，不能混入 ChatGPT/Gemini 上传、发送和原图保护链路。
- 批量颗粒要避免全局固定种子；输入派生种子可以同时满足可复现和跨图差异。
- 原生图片依赖必须在解包程序和覆盖安装后的程序中实测，开发环境能加载不代表安装包环境可用。
- 后续仍需用真实人像人工检查皮肤、头发、服装纹理和 JPEG 损伤程度。
