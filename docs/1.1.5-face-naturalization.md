# 1.1.5 局部人脸自然化

更新时间：2026-08-23

## 功能

- 在结果归档标题栏保留“批量降 AI 感”作为金色主按钮。
- 新增“批量面部自然化”次级按钮，默认选择全部结果，支持逐张勾选、全选、清空和批量进度。
- MediaPipe 人脸关键点和皮肤分割只生成面部区域蒙版；主进程使用 `sharp` 做低强度局部纹理、色彩和噪点统一。
- 原结果不被覆盖；新结果使用 `*_面部自然化.jpg` 命名并加入结果归档。

## 边界

该功能是生成结果的局部后处理，不是 FaceSwap 的身份替换模型。它不能修复错误身份、错误五官、姿态或构图，也不承诺每张图达到与原图“完美一致”的融合效果。识别不到可靠人脸时，该张任务失败并保留原图。
