# 耀创工坊 0.6.14 穿搭提示词原图理解范围优化

日期：2026-08-13

## 问题现象

- 一键生成提示词会无条件写入原图理解中的场景、人物姿态、面部朝向以及光影妆容画质四段内容。
- 上传衣物穿搭参考图后，原图分析里的旧服装、旧场景或人物状态仍可能影响模型对新穿搭参考图的执行。

## 根因

`PromptBuilder` 的原图理解合并函数没有区分普通人脸编辑和包含衣物配饰参考图的任务。只要点击一键生成提示词，它就会把四个分析字段全部拼入最终提示词。

## 解决方式

- 当 `wardrobeReferences` 非空时，原图理解只继承 `lightingMakeupDescription`，即“光影、妆容与画质”区域的内容。
- 场景、人物姿态和面部朝向三个分析字段不再进入该次一键生成提示词。
- 清空衣物配饰参考图后，自动恢复原来的四段完整原图理解行为。
- 原有穿搭素材对应关系、红圈外保护、固定构图约束、附件顺序和人脸参考图职责保持不变。

## 经验教训

- 原图理解不是在所有编辑任务中都应拥有同样权重；加入穿搭参考素材后，应只保留能帮助素材自然融合且不会与新穿搭竞争的光影、妆容和画质信息。
- 提示词规则应根据已经上传的真实素材状态切换，而不是要求用户手动删除分析文本。
- 最小修复应落在统一的提示词拼装入口，避免修改 AI 分析、上传、Provider 或自动化流程。
- 首次安装验证必须先处理首次启动公告；需要真实账号模型的验证与无登录隔离验证应明确分开，不能互相冒充。
