# 耀创工坊 0.5.0 安全审查

## 执行摘要

本次审查覆盖 0.5.0 变更涉及的 React 渲染层、preload、Electron IPC、文件保存、旧版结果恢复、专属 Chrome 管理和诊断日志。未发现 Critical、High 或 Medium 级安全问题。`npm audit --registry=https://registry.npmjs.org` 返回 0 个已知漏洞。

## 已验证控制

1. **渲染隔离**：主窗口和内置自动窗口均使用 `contextIsolation: true`、`nodeIntegration: false`、`sandbox: true`，见 `src/main/index.ts:902`、`src/main/index.ts:6883`。
2. **IPC 来源限制**：所有高权限 `ipcMain.handle` 统一校验主窗口 `webContents`、顶层 frame 和受信页面 URL，见 `src/main/index.ts:6846`。
3. **导航限制**：外部链接只接受 HTTPS 或本机回环 HTTP；打开目录前要求绝对路径和真实目录，见 `src/main/index.ts:813`、`src/main/index.ts:825`。
4. **权限限制**：ChatGPT 会话权限请求由主进程按页面与权限类型审核，见 `src/main/index.ts:1268`。
5. **CSP**：应用壳禁止对象、表单和 frame，脚本只允许自身资源与 WASM，见 `index.html:6`。
6. **密钥不落盘**：设置保存时强制清空 `apiKeySessionOnly`，见 `src/main/index.ts:6995`。
7. **诊断日志脱敏**：敏感键、Bearer 值、URL 账号信息、查询参数和 fragment 在写入前统一脱敏，见 `src/main/diagnosticRedaction.ts:45`、`src/main/index.ts:5979`。
8. **旧数据恢复边界**：只读取版本化 manifest 中列出的普通 JPG，限制清单大小、条目数、图片大小和真实路径；不扫描、不删除、不移动旧文件，见 `src/main/legacyPostProcessingRecovery.ts:117`。
9. **专属浏览器进程边界**：进程终止只匹配专属 `--user-data-dir`，不会结束用户普通 Chrome，见 `src/main/chromeChatGpt.ts:789`。

- `npx oxlint src --deny-warnings`：通过。
- `npm audit`：0 vulnerabilities。

## 残余边界

- 专属 Chrome 登录资料本质上包含用户会话，只保存在独立本地资料目录，不写入日志或安装包。用户仍应保护 Windows 账户和 D 盘权限。
- ChatGPT、Google 登录和模型菜单属于第三方页面。软件可以限制自身行为、记录故障并恢复窗口，但无法控制第三方页面结构、账号策略、网络或服务可用性。
- CSP 的 `style-src 'unsafe-inline'` 用于现有桌面样式体系；脚本策略没有开放 `unsafe-inline`，本次不为追求形式上的收紧而破坏界面。

## 结论

0.5.0 变更范围满足当前 Electron 桌面交付的安全基线。没有需要阻止发布的安全发现。
