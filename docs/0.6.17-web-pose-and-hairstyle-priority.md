# 耀创工坊 0.6.17 网感姿势与主参考图发型优先

日期：2026-08-14

## 问题现象

- 一键生成提示词默认要求延续原图姿态，用户即使希望改变动作，也缺少根据当前画幅和环境生成可执行姿势的入口。
- 直接追加姿势描述会与“不改变身体姿势”“不改变手部”和原图动作分析互相抵消。
- 人脸参考图此前只负责人物身份，提示词多处仍要求头发保持原图，无法稳定以主参考图发型为准。
- `AI 分析`按钮使用绿色语义，与新增加的姿势分析入口层级不统一，也不符合 Hale 要求的金色辅助入口。

## 根因

- 原有项目状态和提示词快照没有姿势建议、当前选择及签名，无法识别旧草稿是否已经包含最新姿势。
- 原图理解、穿搭最高优先级段、Negative Prompt 和操作说明分别维护姿态保护，单点追加新句无法形成完整授权边界。
- ChatGPT 原图分析只接受固定五字段 JSON，不能直接复用来判断 8 条姿势结果是否完整。
- 浅色主题后段通用分析按钮规则会覆盖新增金色样式，需要在最终样式层明确浅色语义。

## 解决方式

- 在`原图理解`标题右侧新增`网感姿势`按钮，使用现有专属 ChatGPT 后台窗口、空白对话、附件预览确认、发送确认和回复抓取链路。
- ChatGPT 根据原图画幅、人物可见范围、服装与环境返回恰好 8 条姿势：1-3 轻微、4-6 适中、7-8 更明显但仍适合当前画幅；不新增道具或强补画幅外肢体。
- 成功返回后才显示按钮下方的小箭头；箭头展开金色实色列表。再次点击主按钮刷新建议，失败时保留旧选项和当前选择。
- 选中姿势后，旧提示词立即失效，必须重新点击`一键生成提示词`；提示词快照保存姿势签名，防止把旧姿势静默发送。
- 姿势授权区限定为目标人物的身体姿态、肩颈、手臂、手部、必要衣物褶皱和遮挡；背景、其他人物、构图、镜头、画幅、环境光和最终像素尺寸继续保持原图。
- 穿搭参考存在时，衣物款式、颜色和材质继续由对应参考图负责，只允许褶皱与遮挡适配新姿势；人脸身份与发型继续由人脸参考图负责。
- 将主参考图发型设为唯一基准，清除正文、负面词、发送说明、操作指南和修正提示词中的旧头发锁。
- `AI 分析`和`网感姿势`统一使用克制金边框；深色、浅色、精确指针 hover、按压反馈及 reduced-motion 均有明确样式。

## 经验教训

- 改变动作不是在提示词末尾追加一句，而是把对应身体区域从保护区转为明确授权区，并同步修正穿搭、负面词和操作说明。
- 动态建议必须和提示词快照绑定签名，否则用户改变选择后仍可能发送旧草稿。
- 刷新型分析应把旧结果保留到新结果完整成功，不能在请求开始时清空用户已经选好的内容。
- 复用成熟浏览器自动化时，仍要为新结构化结果提供独立严格解析；仅看到长文本不能视为 8 条姿势完整返回。
- 深浅主题必须分别看真实截图。语义类按钮在浅色主题中容易被后段通用样式覆盖，单看深色计算值不足以验收。
